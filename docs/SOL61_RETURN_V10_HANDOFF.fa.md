# تحویل مرحلهٔ V10

V10 اجرا و به صفحهٔ رتبه‌بندی متصل شده است. مدل تو‌در‌تو از کنترل فعلی عقب ماند؛ در برنامه با برچسب پژوهشی تاریخی دیده می‌شود و غربال فعلی همچنان پیش‌فرض بررسی است. سفارش واقعی یا زمان‌بندی خودکار ساخته نشده است.

## نتیجه و فایل‌های مرجع

- گزارش کامل: `docs/RETURN_V10_FINAL.fa.md`
- پلن و قرارداد اجرا: `docs/SOL61_RETURN_V10_EXECUTION.fa.md`
- لاگ تغییر موتور: `docs/engine_change_log.fa.md`
- اجرای مهرشده: `ranking_research/output/return_v10/v10_20261018T090000Z/`
- snapshot متصل به رابط: `client/public/research/return-v10.json`
- جزء رابط: `client/src/components/ResearchV10Results.tsx`
- آزمون نهایی: `test_evidence.json` با وضعیت PASS

غربال فعلی با فرمول دقیق روی موتور و دادهٔ V10 به ۲۳۵٫۳۲ میلیون تومان رسید؛ مدل منتخب تو‌در‌تو ۲۰۵٫۴۷ میلیون و کنترل پایهٔ نرمال‌شده ۲۳۸٫۷۶ میلیون تومان شد. نسخهٔ V10 نامزد بهتری برای پیش‌فرض نیست. snapshot رتبه‌بندی تاریخی تا ۲۴ فوریهٔ ۲۰۲۶ است؛ خروجی دادهٔ جاری نیست.

## ادامه یا بازتولید

از `D:\RFA\Company-Financial` و PowerShell:

```powershell
$env:RETURN_V10_RUN_ID = 'v10_20261018T090000Z'
.venv/Scripts/python.exe -B -m ranking_research.return_v10.tests
.venv/Scripts/python.exe -B -m ranking_research.return_v10.run search
.venv/Scripts/python.exe -B -m ranking_research.return_v10.run finalize
```

`search` هش ثبت‌شدهٔ کد و پنل را پیش از ادامه کنترل می‌کند و ردیف‌های کامل‌شدهٔ هر پنجره را از فایل `searches/<window>/experiments.jsonl` بازمی‌گیرد. `finalize` پس از تکمیل حساب بیرونی، snapshot، تشخیص‌ها و شواهد آزمون را تکمیل می‌کند؛ به جست‌وجو یا مسیر حساب دست نمی‌زند. برای اجرای علمی تازه، پنل تازه یا هر تغییر در فضای آزمایش، شناسهٔ اجرای تازه و ثبت پیش از مشاهدهٔ نتیجه لازم است. تغییرهای اجرایی برای حفظ چک‌پوینت‌ها در `execution_amendments.json` مستند شده‌اند.

## نکته‌های تحویل به مرحلهٔ بعد

1. تا رسیدن نتیجهٔ آزمون آینده روی دادهٔ واقعاً بعد از ۲۵ فوریهٔ ۲۰۲۶، تنظیم `next_model.json` را نامزد پژوهشی بدانید؛ ارزش آموزش آن شاهد بازده بعدی نیست.
2. اگر افزودن دادهٔ جاری یا تاریخچهٔ تازه مطرح شد، منشأ، زمان انتشار، پوشش نماد و قرارداد قیمت را جدا قفل کنید؛ پنل همین اجرا را تغییر ندهید.
3. بازده موجود شاخص قیمت تعدیل‌شده است. برای بازده کامل اقتصادی باید سود نقدی، حق‌تقدم، اقدامات شرکتی و امکان اجرا با دادهٔ قابل اثبات فراهم شود.
4. پوشش فروش ماهانهٔ تقویمی عمداً کم است: ۲۴ ماه پیوسته و قابل‌اثبات خواسته شده و ماه مفقود/اصلاح‌شده جعل نشده است. این محدودیت در `coverage.csv` ثبت شده.
5. V8/V9 مهرشده دست‌نخورده‌اند؛ فایل‌های رابط/پژوهش موجود کاربر حفظ شده‌اند. تغییرات Git محلی را پیش از هر پاک‌سازی یا commit جداگانه بررسی کنید.
