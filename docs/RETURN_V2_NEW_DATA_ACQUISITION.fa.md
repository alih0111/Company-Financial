# دریافت جدید قیمت؛ جدا از آزمایش منجمد

برای 254 نماد از 254 نمادِ جامعهٔ قابل‌بازسازی، تاریخچهٔ خام از API رسمی TSETMC دریافت شد. آخرین تاریخ مشاهده‌شده ۲۰۲۶/۱۰/۱۴ است؛ 254 نماد در این تاریخ مشاهده دارند. دیگر نمادها با تاریخ واقعی آخرین مشاهده در inventory.csv حفظ شده‌اند؛ توقف/حذف از این عدد استنتاج نشده است.

این داده‌ها وارد عملکرد منجمد این چرخه نشده‌اند. بستهٔ مصرفیِ بک‌تست همان قرارداد داده و بازهٔ ثبت‌شده است. دریافت متأخر، آزمون مستقل یا رتبه‌بندی امروز ایجاد نمی‌کند. نسخهٔ گزارش‌های جدید، تعداد سهام/رویدادها و جامعه نیز باید برای تاریخ تصمیم بازسازی شوند؛ صرف داشتن قیمت تازه برای انتشار رتبه‌بندی کافی نیست.

اعتبارنامه یا API کارگزاری لازم نبود؛ درخواست‌ها عمومی، محدود به حداکثر یک درخواست در ثانیه و دارای checkpoint بودند. هیچ منبع قدیمی یا RAW اصلی بازنویسی نشد.

مسیر داده: `ranking_research\output\return_v2\v2_20261015T201421684069Z\new_market_archive`.

فرمان واقعاً اجراشده و قابل ادامه (فایل‌های کامل را دوباره دانلود نمی‌کند):

```powershell
.venv/Scripts/python.exe -B -m ranking_research.tests.acquire_return_v2_current_prices "ranking_research\output\return_v2\v2_20261015T201421684069Z"
```


کنترل تکمیلی: هش منبعِ هر۲۵۴ فایل باز شد و تطبیق یافت. 244 نماد در۱۴اکتبر معامله با حجم/ارزش مثبت دارند؛ وجود رکورد روزانه برای بقیه به معنی معامله یا نقدشوندگی نیست. 268 ردیف تاریخیِ هم‌پوشان بین بستهٔ قبلی و دریافت جدید متفاوت است؛ فایل‌های قبلی حفظ شده‌اند و تغییرها وارد نتایج منجمد نشدند. جزئیات در current_quality.csv و historical_changes.csv ثبت شده است.
