# دسترسی فقط‌خواندنی پیشرو

در بررسی عمومی ۲۰۲۶-۱۱-۱۳، کارگزاری نشانی پنل آنلاین را در کانال خود اعلام کرده است. در منابع عمومی بررسی‌شده مستندات API خواندن حساب، قواعد احراز هویت یا قرارداد واحد و صفحه‌بندی پیدا نشد. [اطلاعیهٔ کارگزاری](https://t.me/s/pishrobroker?before=14666)

`live_broker/pishro.py` قرارداد داخلی یک خروجی نرمال‌شده را روی نمونهٔ ساختگی می‌سنجد. پیش از استفاده از حساب، مسیر مجاز دریافت، واحدهای واقعی و معیار کامل‌بودن هر گزارش باید مشخص شوند. آزمون parser فقط رفتار اعتبارسنجی ورودی را پوشش می‌دهد.

اگر نشست منقضی شد، سامانه `SESSION_EXPIRED` گزارش می‌کند و داده را نمی‌پذیرد. ورود دوباره در پنل توسط مالک انجام می‌شود. قابلیت‌ها پس از خواندن مجاز و اعتبارسنجی هر منبع جداگانه تغییر وضعیت می‌دهند. دریافت و پذیرش snapshot از تغییر دفتر و موجودی جدا می‌مانند.

## پیگیری اتصال برای سفارش خودکار، ۱۸ نوامبر ۲۰۲۶

ورود در Chrome با فرم تکمیل‌شده به داشبورد آنلاین پلاس رسید. پنل خرید، فروش و سفارش‌ها دیده شد. در تنظیمات بررسی‌شده گزینهٔ API یا کلید دسترسی دیده نشد. سایت پیشرو آنلاین پلاس و دو سامانهٔ الگوریتمی «گرگی» و «امید» را معرفی می‌کند. تدبیرپرداز از API برای نهادهای مالی طرف قرارداد خبر داده است. دسترسی نرم‌افزار خارجی برای حساب مورد نظر، مستندات سفارش و محیط آزمون هنوز تأیید نشده‌اند. [سامانه‌های پیشرو](https://pishrobroker.ir/home/trades) · [اعلام تدبیرپرداز](https://ir.linkedin.com/company/tadbirpardaz-it-group)

دفتر سفارش با `003_submission_receipts.sql` می‌تواند شناسهٔ سفارش پذیرفته‌شده را در محدودهٔ همان حساب ذخیره و رسید خرید یا فروش را بر اساس همان شناسه ثبت کند. پاسخ مبهم یا شناسهٔ متناقض رزرو را حفظ می‌کند و ارسال بعدی حساب را متوقف می‌کند. مسیر ارسال به پیشرو، پیگیری پاسخ نامشخص از خود کارگزاری و خواندن واقعی حساب به قرارداد اتصال وابسته‌اند.

پرسش برای واحد فنی پیشرو این است که آیا برای حساب حقیقی می‌توان دسترسی ارسال خودکار سفارش نقدی از نرم‌افزار خارجی را فعال کرد. در صورت امکان، مستندات احراز هویت، ارسال و پیگیری سفارش، خواندن معاملات و موجودی و شیوهٔ آزمون را درخواست کنید. [تماس با پیشرو](https://pishrobroker.ir/home/contact-us)
