# گزارش اجرای V12.3 — رتبه‌بندی و منشأ بازده

وضعیت: **PARTIAL**؛ شناسهٔ اجرای نهایی `v12_3_20261019T143000Z`.

## رتبه‌بندی جاری و داده

مسیر موجود `/ranking/research/v12-1` حفظ شد و بخش تحلیل V12.3 به همان صفحه اضافه شد. URL محلی پاسخ HTTP 200 می‌دهد: `http://127.0.0.1:5173/ranking/research/v12-1`. snapshot رتبه‌بندی همچنان تاریخی است: قیمت تا 2026-02-25، cutoff اطلاعات 2026-02-24، ۲۵۰ نماد امتیازگرفته از cohort ثابت ۲۵۴تایی P3. **هیچ رتبهٔ تازهٔ بازار در V12.3 ساخته نشد**؛ شمار سهام جاریِ واجد شرایط و آخرین جلسهٔ کامل همچنان نامعلوم و شمار رتبه‌گرفتهٔ جاری صفر است. اعداد ۲۴۳ هویت stock فعال و ۸۳۳ مورد unresolved از pull تشخیصی V12.2 هستند، نه اندازهٔ بازار.

بازرسی کد ادعای نبود مسیر انتشار را اصلاح کرد: `provenance_v1/codal_publish_resolver.py`، overlay مالی تأییدشده و recompute موجودند؛ ۲۳ آزمون resolver و timezone گذشتند. ۲۳۷ cache نامهٔ کدال و ۲۵۶ cache fact در مسیر verified پیدا شد. این مسیرها شواهد زمان انتشار و fact فراهم می‌کنند، اما اتصال یکپارچه و قابل‌بازتولید به شناسهٔ ابزار/قیمت و فرمول دقیق ۲۱ عامل V12 در جامعهٔ جاری احراز نشد. Q/V/T قرارداد امتیاز دیگری دارد و به‌عنوان جایگزین استفاده نشد. نقشهٔ ۲۱ عامل و محدودیت منبع هر کدام در `factor_source_map.csv` است.

از ۸۳۳ unresolved موردی در این اجرا به‌صورت تازه و مستند resolve نشد. موارد با شناسهٔ پایدار ناموجود یا اتصال شرکت/ابزار متعارض قرنطینه ماندند؛ alias و شباهت نام برای ادغام استفاده نشد. تعداد eligible و درصد پوشش کل بازار `null` است.

## منشأ بازده P3

شش replay و انتساب قبلی V12.2 از روی مصنوعات مهرشده بازاستفاده شدند؛ محاسبهٔ ۱۲۲۴ گزینه یا انتخاب سیاست گذشته تکرار نشد. برای w0/P_staged، سرمایه از ۱۰۰ به **۳۳۴٫۲۸۸ میلیون تومان** رسید: سود/زیان قیمت +۲۵۲٫۱۸۶ میلیون، هزینه ۱۷٫۸۹۹ میلیون، معاملات ۱۵۷ و باقیماندهٔ آشتی NAV حدود ۰٫۰۰۰۰۰۰۲ تومان. پنج نماد مثبت نخست عبارت‌اند از حفاری، سپیدار، ساربیل، دارو و کپارس؛ سهم مجموع آن‌ها از مشارکت مثبت نمادها ۷۷٫۳۷٪ است. بزرگ‌ترین بلوک‌ها بلوک ۳ (+۶۷٫۹۱ میلیون) و بلوک ۵ (+۶۵٫۶۳ میلیون) بودند؛ بلوک اول ۸٫۹۲ میلیون افت داشت. پس سود در چند بلوک پخش شده، اما مشارکت نمادی به چند نام برتر متمرکز است. این انتساب تاریخی، سیگنال آینده نیست.

دو کنترل ازپیش‌ثبت‌شده، w0/N=10/equal/exit=1 روی همان دورهٔ 2021-04-03 تا 2026-02-25 بودند:

| بازبینی | سرمایهٔ پایان | هزینه | معاملات | میانگین مدت تا فروش، روز تقویمی |
|---|---:|---:|---:|---:|
| هر ۲۱ جلسه | ۳۳۳٫۸۷۹ میلیون | ۳۷٫۸۶۲ میلیون | ۸۹۵ | ۱۰۱٫۸ |
| هر ۶۳ جلسه | ۲۷۹٫۳۷۳ میلیون | ۱۸٫۲۶۷ میلیون | ۳۷۶ | ۱۵۵٫۰ |

کنترل ۲۱جلسه‌ای به عدد P_staged نزدیک شد، اما این به‌تنهایی توضیح علّی یا نتیجهٔ holdout نیست؛ کنترل‌ها و P3 همان سابقهٔ دیده‌شده را دارند. cadence فاصلهٔ تصمیم‌هاست و با مدت واقعی نگهداری یکی نیست. NAV دو کنترل از دفتر مستقل معاملات بازسازی شد؛ بیشترین خطا کمتر از یک میلیونیم تومان بود.

وزن‌ها **تغییر نکردند**. `staged_v12_last_block` همان بردار دقیق بلوک آخر است و مسیر w0 با وزن نقدشوندگی صفر ثابت ماند. برتری ۳۳۴ میلیون به توالی شش سیاست/وزن منتخب تعلق دارد؛ وزن آخر به‌تنهایی آن بازده را نساخته است. شواهد مقایسهٔ شش‌مسیره و اختلاف وزن مشترک همان دادهٔ مهرشدهٔ V12.2 است.

## آزمون‌ها و ادامه

موفق: ۲۳ آزمون resolver انتشار و timezone؛ نقشهٔ ۲۱ عامل؛ آشتی انتساب سه مسیر منتخب با NAV؛ replay هر دو کنترل و آشتی مستقل ۱۱۶۷ مشاهده برای هر کنترل؛ build تولیدی کلاینت؛ smoke HTTP برای route و هر دو JSON با پاسخ 200. هش مصنوعات و منابع در `delivery_manifest.json` ثبت است.

مسدود: snapshot جاری ۲۱عامل، تطبیق authoritative موارد هویتی، denominator بازار و freshness جلسه؛ تست browser واردشده/موبایل/تعامل CSV؛ و ارزیابی مستقل پس از P3. Vite build و HTTP جای تست تعاملی مرورگر نیستند. دادهٔ پس از P3 به علت نامشخص‌بودن سابقهٔ استفاده و PIT، holdout نام نگرفت. روش مرجع w0، انتخاب سیاست با w0 و انتقال سیاست تعریف شده‌اند؛ انتخاب سیاست روز unavailable است تا ورودی PIT و cutoff آن قابل اثبات شود.

بازکردن همین صفحه: `http://127.0.0.1:5173/ranking/research/v12-1`. فرمان بازتولید تحلیل V12.3 از ریشهٔ مخزن:

```powershell
$env:RETURN_V12_3_RUN_ID = 'v12_3_20261019T143000Z'
.\.venv\Scripts\python.exe -B -m ranking_research.return_v12_3.run
cd client
npm run build
```

اجرای جدید باید run id یکتا بگیرد؛ اجرای دوباره با run id مهرشده عمداً رد می‌شود. refresh صفحه فقط JSON را دوباره می‌خواند و ingest بازار نیست.
