## Coverage bias

The dominant finding: canonical-v1's score is strongly correlated with the number
of available factors (dev 0.576, holdout 0.575), i.e. high-coverage companies are
rewarded. All v2 candidates cut this dramatically (exp-a 0.055/0.115). This is the
main structural improvement, independent of raw return.

## Stability

Yearly and per-stratum views: `output/model_v2_portfolio.csv`,
`output/model_v2_coverage.csv`. Development favours exp-a strongly; validation is
close (exp-b best IC, baseline best return); holdout reverses the return ranking
(baseline 0.747 vs exp-a 0.636) while IC is comparable and coverage bias stays far
lower for v2.

## Baseline comparison discipline

All models scored the identical frozen snapshot (same universe, PIT, return
construction, portfolio construction, cost scenario, periods). No cross-experiment
comparison.
