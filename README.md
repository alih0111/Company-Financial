# RFA — بینش شرکت‌ها

سامانهٔ فارسی تحلیل شرکت‌های بورسی، غربال بازار، صورت‌های مالی و سبد شخصی.

- رابط: React، TypeScript و Vite؛ راست‌به‌چپ و واکنش‌گرا.
- API: Go و Gin؛ نشست مرورگر با کوکی HttpOnly و لغو سمت سرور، نقش مدیر و سبد مستقل هر کاربر.
- داده: PostgreSQL با ساختار canonical؛ پردازش و دریافت داده با Python.
- انتشار: Docker Compose و Caddy؛ فرانت و API با یک دامنه.

راهنمای کامل نصب، HTTPS، انتقال دادهٔ بازار، ساخت مدیر، پشتیبان‌گیری و محدودیت‌های فعلی: **[deploy/README.fa.md](deploy/README.fa.md)**.

گزارش کنترل‌های امنیتی، ارتقای دیتابیس و محدودیت آزمون‌ها: **[deploy/SECURITY.fa.md](deploy/SECURITY.fa.md)**.

راهنمای حفاظت از داده، سهمیهٔ کاربران و خصوصی‌کردن منبع پیش از انتشار: **[deploy/DATA_PROTECTION.fa.md](deploy/DATA_PROTECTION.fa.md)**.

## توسعهٔ محلی

در `go-app/.env` مستقل، متغیرهای نمونهٔ `go-app/.env.example` را تنظیم کنید. Go نسخهٔ 1.26.10 یا جدیدتر و کلید JWT تصادفی حداقل ۳۲ بایتی برای سازگاری ابزارهای توسعه لازم است. پیش از اجرای نسخهٔ جدید روی دیتابیس موجود، migration نشست‌ها را مطابق راهنمای امنیت اعمال کنید. ثبت‌نام بدون تنظیم SMTP بسته می‌ماند؛ ورود حساب موجود مستقل از SMTP است.

```powershell
cd client
npm ci
npm run dev
```

در ترمینال دیگر:

```powershell
cd go-app
go run .
```

فرانت روی پورت ۳۰۰۰، مسیر `/api` را به پورت ۵۰۰۰ می‌فرستد. برای اجرای یکپارچه، `npm run build` را اجرا و `FRONTEND_DIR=../client/dist` و `PUBLIC_ARTIFACTS_DIR=../client/public` را در تنظیمات بک‌اند قرار دهید.

## بررسی‌ها

```powershell
cd go-app
go test ./...
cd ../client
npm run build
npm test
```

تست‌های واقعی PostgreSQL فقط با `RFA_DEPLOY_TEST_DSN` صریح و دیتابیس محلی با پیشوند `company_financial_test_` اجرا می‌شوند. `.github/workflows/verify.yaml` بررسی کد، race detection، نصب ساختار دیتابیس و ساخت و دودآزمایی Docker را برای CI تعریف می‌کند.

## داده و حریم خصوصی

فایل‌های `.env`، حساب‌های محلی، اطلاعات کارگزاری، dump دیتابیس، ورودی‌های پژوهشی محلی و پوشه‌های اجرا جزو تصویر عمومی نیستند. دادهٔ بازار و بسته‌های لازم برای بازسازی مدل باید از مسیر مستند جداگانه منتقل شوند. نتایج تاریخی موجود، دادهٔ تازهٔ بازار یا تضمین عملکرد مدل نیستند.
