پلن «ارتقا به سطح نرم‌افزار جهانی» — فازبندی‌شده

═══ تصمیم ساختاری: چند صفحه؟ ═══
تعداد صفحات درسته و کم/زیادش نمی‌کنم: ۷ مسیر (لندینگ، ورود، ثبت‌نام، داشبورد شرکت، غربال بازار، پورتفولیو، دارایی خانواده). ادغام پورتفولیو با دارایی خانواده اشتباه است چون مخاطب و دامنه‌ی داده متفاوتند (کاربر عادی vs ادمین). مشکل واقعی، ناوبری و یکدستی است که در فاز A حل می‌شود.

═══ فاز A — ناوبری و ساختار (IA) ═══
1. سایدبار: منوی ناوبری واقعی با NavLink + آیکون + حالت فعال (داشبورد / غربال بازار / پورتفولیو / دارایی خانواده فقط ادمین) — حذف کامل سلکت «Home/Table/Portfolio» (NavigationButton.tsx حذف می‌شود). سلکت جست‌وجوی شرکت سر جایش می‌ماند.
2. روت `/Table` هم ProtectedRoute بگیرد (الان بدون محافظ است) و عنوان‌های document.title یکدست فارسی شوند.
3. login/register اگر توکن معتبر باشد به /dashboard ریدایرکت شوند.
4. صفحه‌ی 404 جدید (NotFound.tsx) + مسیر catch-all.
5. کلیک روی ردیف جدول داده: به جای بازکردن سایت قدیمی rfa.systemgroup.net در تب جدید، داخل همان اپ به /dashboard?companyname=... برود.
6. index.html: lang="fa" و dir="rtl"، favicon اختصاصی (SVG چارت سبز)، meta description/theme-color.
7. فونت وزیرمتن واقعاً لود شود — الان فقط در CSS نام برده شده و به Tahoma fallback می‌کند! با پکیج npm خودش (self-host، بدون وابستگی به CDN که در ایران ناپایدار است) + font-display: swap.

═══ فاز B — حذف کد مرده و سبز شدن بیلد ═══
1. حذف فایل‌های مرده (تأییدشده بدون import خارجی): AIStockTable.tsx، MergedStockTable.tsx، GaugeChartComponent.tsx، StockChartComponent.tsx، CompanySelect.tsx، ProtectedLayout.tsx، utils/aiStockApi.ts، App.css و import بلااستفاده‌ی AIStockTable از App.tsx.
2. حذف client.zip و public.zip از ریشه‌ی client (بک‌آپ‌های قدیمی داخل ریپو — اگر خواستی نگهشان داری بگو تا حذف نکنم).
3. حذف وابسته‌ها: plotly.js، react-plotly.js، react-financial-charts، use-resize-observer، styled-components، xlsx، file-saver، jalaali-js و پکیج‌های اشتباهی `install` و `npm`. (react-table و react-select و react-icons می‌مانند — استفاده‌ی فعال دارند.)
4. رفع ۳۴ خطای tsc تا `npm run build` (tsc + vite) سبز شود: تایپ‌های data1/data2 و companyProfits در App.tsx، DataRow در BigDataTable و چند unused متغیر.
5. رفع خطر ترتیب هوک در ScriptFullModal.tsx (useState بعد از early-return).

═══ فاز C — پرفورمنس ═══
1. React.lazy + Suspense (با Skeleton) برای هر صفحه: Landing، Login، Register، داشبورد، Table، Portfolio، FamilyAssets.
2. manualChunks در vite.config: vendor (react)، recharts، lightweight-charts جدا شوند تا باندل ۱٫۲ مگابایتی فعلی تکه شود.

═══ فاز D — پیکربندی متمرکز ═══
1. src/config.ts با API_BASE از متغیر VITE_API_BASE (fallback به آدرس فعلی) — استفاده در api.ts، Login، Register.
2. .env.example برای مستندسازی.

═══ فاز E — تأیید نهایی ═══
1. npm run build سبز + گزارش حجم چانک‌ها.
2. اسکرین‌شات همه‌ی صفحات در دو تم با ?__mock=1 و چک عرض موبایل (390px) برای داشبورد و سایدبار.
3. گزارش خلاصه‌ی تغییرات.

ترتیب اجرا: B → A → C → D → E (اول پاکسازی تا زیر ساخت تمیز شود).
مجموع تقریبی: حذف ۸ فایل + ~۱۰ فایل تغییر + ۲ فایل جدید (NotFound، config).
